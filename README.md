# kevinmsong.github.io

Personal portfolio for [Kevin Song](https://github.com/kevinmsong), PhD candidate in Biomedical Engineering / Bioinformatics at the University of Alabama at Birmingham.

The live site is [kevinmsong.github.io](https://kevinmsong.github.io). GitHub Pages serves [`index.html`](index.html), [`styles.css`](styles.css), and [`favicon.svg`](favicon.svg) from the root of the default branch (`main`). There is no build step. [`.nojekyll`](.nojekyll) keeps Pages from processing the site with Jekyll.

For research directions, toolkit, and selected work, see the [profile README](https://github.com/kevinmsong/kevinmsong).
